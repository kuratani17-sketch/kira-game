# キラゲームDX Ver.0.6 — 既存の公開URLを更新する方法

前回のGitHubリポジトリ `kira-game` とRenderのWeb Serviceは、そのまま使えます。

## 既存リポジトリへのアップロード

1. ダウンロードしたZIPをPCで解凍します。
2. GitHubで `kira-game` リポジトリを開きます。
3. 一番上の階層で `Add file` → `Upload files` を選びます。
4. 解凍した **`kira-game-dx-discord-render` フォルダを丸ごと**アップロード画面にドラッグします。中身のファイルは同名の既存パスへ更新されます。
5. `Commit changes` を押します。更新された `server.py` と `public/index.html` の両方が `kira-game-dx-discord-render` 内にあることを確認してください。
6. RenderのWeb Serviceで自動デプロイが始まり、`Live` になれば更新完了。自動更新されなければ `Manual Deploy` → `Deploy latest commit` を使います。

**フォルダを二重に作らないでください。**

- 正：`kira-game-dx-discord-render/server.py`
- 正：`kira-game-dx-discord-render/public/index.html`
- 誤：`kira-game-dx-discord-render/kira-game-dx-discord-render/server.py`

Renderで以前に `Root Directory` を `kira-game-dx-discord-render` に設定していれば、**変更不要**です。

## Renderの設定を確認するとき

`Settings` → `Build & Deploy` 内に以下が入っているか確認してください。

- Root Directory：`kira-game-dx-discord-render`
- Build Command：`pip install -r requirements.txt`
- Start Command：`python server.py`

## 今回の追加機能（Ver.0.6）

待機部屋に5〜10人戦のおすすめ役職配分表を追加しました。選択中の人数が目立つようになり、ホストは「この人数のおすすめを設定欄へ入力」で役職構成を一括入力できます。その後 **「設定を保存」** を押してください。参加者は配分表を閲覧できますが、ゲーム設定は変更できません。

8・10人戦は全役職入りの構成を標準表示し、別案も開閉欄から閲覧できます。11・12人戦では推奨配分未検証と表示します。

## 更新後のチェック

1. 待機部屋に5〜10人の配分表があり、人数変更で行が強調表示される。
2. ホストが「この人数のおすすめを設定欄へ入力」を押すと、崇拝者・ワタリ・ジェバンニ数が切り替わる（「設定を保存」するまで未反映）。
3. 役職確認や検挙結果の中央オーバーレイに「自分だけ退出」が表示されない。画面右上の「退出」は残っている。
4. NPCの名前が指定された14種類からランダムに選ばれる。
5. ホームのジェバンニ説明が「護衛成功者を指名した場合は疑惑度を下げる」になっている。
6. 裁きでL以外が脱落したとき、崇拝者は公開候補に入らない。
7. それ以外の機能も従来どおり動作する。

既存URLは変わりません。Renderがデプロイする際、進行中の試合は失われることがあるので、プレイしていないときに更新してください。
