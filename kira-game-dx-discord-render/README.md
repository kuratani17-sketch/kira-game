# キラゲームDX Ver.0.5

Discordで音声会話しながら、スマホ・PCのブラウザから遊ぶ5〜12人用オンライン正体隠蔽ゲームです。人間は1人以上、足りない人数はNPCが補充されます。

## Renderで公開・更新

既存の `kira-game` GitHubリポジトリ内 `kira-game-dx-discord-render` を上書き更新するだけです。既存のRenderサービス・公開URLは維持できます。くわしくは `公開手順.md` を参照。

- Root Directory：`kira-game-dx-discord-render`
- Runtime：Python
- Build Command：`pip install -r requirements.txt`
- Start Command：`python server.py`

手元で実行する場合：`pip install -r requirements.txt` → `python server.py` → `http://localhost:8080`。

## Ver.0.5の更新点

1. 結果・役職確認の中央オーバーレイから「自分だけ退出」ボタンを削除しました。**画面右上の「退出」ボタン**は維持します（オーバーレイを「確認した」で閉じてから利用）。ホスト専用の「待機部屋へ」もそのままです。
2. NPCの表示名を **夜神／竜崎／相沢／模木／松田／魅上／伊出／音原田／渋井丸／火口／弥／ペンバー／南空／マット** の14種類からランダム選択。同一試合内での名前重複を避け、人間がすでに使用している名前も除外します。
3. キラの「裁き」で **L以外が脱落したとき** に公開される人物を、**生きているキラ・崇拝者以外の人物（L陣営）** からランダム選択するよう変更。未公開者を優先し、公開された人物は疑惑度0／以後の指名・検挙の対象外になります。裁きが護衛で防がれたり、裁き自体を使わなかったときは新たな公開は発生しません。公開候補がいない場合も新たな公開はありません。
4. NPCジェバンニは夜、前夜に護衛した人物以外から生存者をランダムに選択。昼の指名対象はランダムですが、**以前に裁きから守ることに成功した相手を指名対象に選んだ場合は、必ず疑惑度を下げます**。その他の指名は上げ下げともランダムです。ホームのNPC立ち回り説明も変更しました。

Ver.0.4の機能（初期時間40秒／20秒、日別指名履歴、調査バッジ、L以外のL陣営の全滅判定、役職イラスト、待機部屋復帰など）は引き続き利用できます。

## 主な基本ルール

- 役職：キラ／崇拝者（キラ陣営）、L／捜査員／ワタリ／ジェバンニ（L陣営）。キラとLは各1名必須、残りのうち最低1名は捜査員。
- 昼は「議論→指名」を3回行い、終了後に生存するキラ候補の中で疑惑度最高の人物を検挙。同点はランダム。議論は時間切れ、またはホストの手動終了。
- 指名の変化幅：1日目±1、2日目±2、3日目±3……。疑惑度は初期値0、マイナスにもなり、翌日へ引き継ぎます。
- 夜はキラが裁き（パスも可能）、Lが調査、ジェバンニが護衛。NPCキラは50％で裁きを行い、対象はランダム。NPCジェバンニは連夜に同じ対象を護衛しません。
- 夜にキラがL以外を裁いた場合、生存中のL陣営1人（キラでも崇拝者でもない人物）を公開（未公開者優先）。公開でキラでないと確定した人は疑惑度が0になり、以降の指名・検挙対象から除外されます。
- 脱落者の役職を公開するかはホストが開始前に設定できます。ゲーム終了時は全役職を公開。
- 役職配布時、イラストつきの役職カードを画面中央に表示。崇拝者はキラ、ワタリはLの正体を初期から把握します（各自の画面だけ）。
- 【公開情報】と公開履歴は別欄。タイマー・疑惑度・指名操作はスマホでも1画面内に表示し、人数が多いときは各パネル内スクロール。

## 制限・注意

- ゲーム内音声通話は実装していません。Discordを別途使ってください。
- NPCは音声の内容を理解できず、定義されたルールで動きます。
- 対戦データはサーバーメモリ上にあり、Renderのスリープ・再起動・デプロイで消えることがあります。
- 進行中のゲームへの新規参加はできません。同じタブセッションからの再接続は可能です。途中退出者の席はその試合中は残ります。
- ホストが待機部屋へ戻すと進行中の対戦は破棄されます。再開すると新たに役職が配布されます。
- Render実公開環境での長時間連続対戦は未検証です。
