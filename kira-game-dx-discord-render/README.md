# キラゲームDX

PC・スマホのブラウザから、同じ部屋コードに入って遊べるリアルタイム正体隠蔽ゲーム。

## 起動

Python 3.10以上が必要です。

```bash
pip install -r requirements.txt
python server.py
```

`http://localhost:8080` にアクセスすると、新しい部屋を作れます。
部屋コードか招待URLを共有すると他の人が参加できます。

## インターネットへの公開

RenderなどのPython Web Serviceにこのフォルダをデプロイします。
- Build command: `pip install -r requirements.txt`
- Start command: `python server.py`
- `PORT` 環境変数が自動的に反映されます。
- この試作版の部屋情報はサーバーメモリ上にあり、再起動で消えます。

## 基本ルール

- 全体5〜12名、人間1名以上。足りない枠はNPC。
- キラ1名、L1名が必須。崇拝者、ワタリ、ジェバンニの人数を設定し、残りは捜査員。
- 昼は議論と指名（±1）を3回繰り返して最大疑惑度の1人を検挙。同点なら抽選。
- 夜はキラが裁き、Lが調査、ジェバンニが護衛。裁き対象が護衛されていれば脱落なし。
- Lかキラが検挙された時、Lが裁かれた時、捜査員が全滅した時に終了。

## 試作版での補完ルール

- 疑惑度は0から開始し、マイナスも許可。上限・下限なし。前日の疑惑度は翌日に持ち越します。
- 議論は設定された時間で自動終了しますが、ホストは「議論を終了して指名へ進む」で早めに終了できます。
- 指名の制限時間は30秒固定。未入力プレイヤーの指名は自動選択。
- 役職は勝負終了時に全員公開。検挙・裁きの対象者の役職も公開。
- NPCキラは各夜50%の確率で裁きを使用し、使用するときは生存している他人からランダムに選びます。人間のキラは裁きを使わずに夜を終えることもできます。
- 裁きが成功し、犠牲者がL以外なら、キラでない人物をランダムで1人公開（犠牲者以外）。
- 「【公開情報】」は公開履歴から独立して画面右側に累積されます。自分の役職や公開された役職には、キラ陣営＝赤、L陣営＝青の色を付けます（未公開の役職は色で推測できません）。
- 議論はDiscordなど外部の通話を使ってください。ゲーム内には音声通話・マイク操作はありません。
- 捜査員が0人の場合、ゲーム開始時点でキラ陣営が勝利してしまうため、捜査員を最低1人残す設定を推奨。

## 現状の制限

- プレイヤーの発言内容はNPCには入力されず、NPCの指名や能力は指定されたルールに基づく自動処理です。
- 役職の人数と設定の変更は開始前のみ。
- 途中参加不可、再接続は同一ブラウザ・同一タブセッション内に限ります。
- ユーザー認証・永続DB・モデレーション機能は未実装です。
