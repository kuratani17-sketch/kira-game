# キラゲームDX Ver.0.3

Discordで会話しながら、PC・スマホのブラウザから遊ぶ5〜12人用オンライン正体隠蔽ゲームです。人間は1人以上、足りない人数はNPCが補います。

## Renderで公開する

以前の `kira-game` GitHubリポジトリ内にある `kira-game-dx-discord-render` フォルダを更新するだけです。既存のRenderサービスと公開URLはそのままでOKです。詳細は `公開手順.md` を参照。

- Root Directory: `kira-game-dx-discord-render`
- Runtime: Python
- Build Command: `pip install -r requirements.txt`
- Start Command: `python server.py`

手元で起動する場合は `pip install -r requirements.txt`、`python server.py`、`http://localhost:8080` の順です。サーバーのPORT環境変数を自動で使います。

## ゲーム

- 役職：キラ、崇拝者、L、捜査員、ワタリ、ジェバンニ。キラ・L各1名必須、その他は人数指定、残りは捜査員（最低1名）。
- 昼は議論→指名を3回繰り返し、指名ごとに全員が誰かの疑惑度を上げるか下げる（マイナスも可）。時間切れか、ホストの手動操作で議論終了。
- 指名ポイントの変動：1日目±1、2日目±2、3日目±3……。疑惑度は初期値0、翌日以降も継続。
- 3回終了すると、キラ候補の生存者で疑惑度が最も高い人物を検挙。同点者はランダム。
- 夜、キラは裁き（スキップ可）、Lは調査、ジェバンニは護衛を実施。NPCキラは50％でスキップし、使用時は生存する他人からランダムに対象を選ぶ。
- L以外が裁きで脱落したら、**その時点で生存している非キラ**から原則未公開者を1人公開し、その人物を「キラ候補から除外」とします。疑惑度は即座に0、指名と検挙の対象になりません（夜能力の対象にはなれます）。
- 脱落時の役職公開 ON/OFF を部屋の設定画面で選択できます。OFFの場合は試合途中の脱落者の役職・陣営色を一般公開しません。試合終了時は全役職を公開します。
- キラを検挙すればL陣営の勝利。Lの検挙・裁き、あるいは捜査員全滅ならキラ陣営勝利。
- 各役職の説明は参加前のホーム画面に表示。ゲーム開始時に12秒間、配布された役職とイラストを画面中央に表示します。
- ゲーム中、制限時間・疑惑度リスト・指名操作がPC/スマホともに1画面に収まるよう設計。人数が多い場合は疑惑度リストだけ内部スクロールします。
- 初期情報として確定している役職を名前の横に表示します。崇拝者はキラ、ワタリはLを自分の画面だけで確認できます。未確定の役職は他人に漏れません。
- 【公開情報】と公開履歴は別パネルです。

## 現段階の制限

- 通話機能は含まれていません。議論中だけDiscordを使い、その他の時間は各自ミュートしてください。
- NPCは人間の音声や議論内容を理解しません。指定された役職行動に従います。
- ルーム状態はサーバーのメモリ上に保存されます。Renderの再起動や新しいデプロイで消えます。
- 部屋は開始後の新規参加は不可。再接続は同じタブセッションのブラウザ更新で対応します。
- Render上での実際の複数スマホによる長時間対戦は未検証です。
