# キラゲームDX v0.2：既存のGitHub / Renderを更新する方法

このZIPは、すでにGitHub `kira-game` にある **`kira-game-dx-discord-render`** フォルダと同じ名前のフォルダを収録しています。ゲームのURLやRenderサービスを作り直す必要はありません。

## すでにGitHub / Renderに公開した人（今回はこちら）

1. ZIPをPCで**解凍**します。フォルダ名は `kira-game-dx-discord-render` です。
2. GitHubで現在の `kira-game` リポジトリを開きます。
3. ルート階層（青いフォルダ `kira-game-dx-discord-render` が見える画面）で、`Add file` → `Upload files` を押します。
4. 解凍した `kira-game-dx-discord-render` **フォルダそのもの**をアップロード画面へドラッグ＆ドロップします。GitHubはフォルダのドラッグ＆ドロップに対応しています。
5. 更新先が `kira-game-dx-discord-render/server.py` と `kira-game-dx-discord-render/public/index.html` になっていることを確認し、`Commit changes` します。**2重フォルダ** (`kira-game-dx-discord-render/kira-game-dx-discord-render/...`) にしないでください。
6. Renderの `kira-game` のWeb Service（キラゲームDX用）を開き、デプロイ完了を確認します。自動デプロイが無効なら `Manual Deploy` → `Deploy latest commit` を実行してください。

Render 設定は前回のままでOKです：

- Root Directory: `kira-game-dx-discord-render`
- Build Command: `pip install -r requirements.txt`
- Start Command: `python server.py`

※更新のためにアプリとサーバーが再起動すると、それまでの進行中の部屋は消えます。対戦が終わったあとに更新してください。

## 新しいリポジトリで公開する場合

新しく作る場合は、解凍したフォルダの**中身**をGitHubのリポジトリ直下に置き、Renderの Root Directory は空欄にします。Render Web ServiceのRuntimeはPython、Build/Start Commandは上記と同じです。

## 更新内容

- 議論の手動終了ボタン（ホスト限定）。自動時間切れも従来どおり。
- 右下の「議論について」パネルを削除。音声はDiscordを利用。
- 疑惑度を0から開始、マイナス許可、翌日にも持越し。
- 既知の役職・勝敗表示を陣営カラー（キラ＝赤、L＝青）に変更。未公開役職の陣営は表示しません。
- NPCキラは50%で裁きを見送り、使うときは対象をランダム選択。
- 「【公開情報】」を公開履歴から分離して累積表示。

## 注意

- サーバーはWebSocket接続を使います。Renderでは **Web Service** として公開してください（Static Siteでは動きません）。
- Renderの無料プランはしばらくアクセスがないと休止し、復帰までに時間がかかります。
- 対戦データはメモリ上なので、サーバー再起動で消えます。
- 複数端末からの公開URLでの実戦検証は未実施です。公開後に2端末で操作を確認してください。
