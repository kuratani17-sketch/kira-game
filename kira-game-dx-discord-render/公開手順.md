# キラゲームDX：GitHub・Render公開手順

この手順はPCのブラウザだけで実行できます。スマホで遊ぶ人は公開後のURLを開くだけです。

## 1. GitHubにアップロード

1. https://github.com/new を開き、ログインします。
2. Repository name を `kira-game-dx` に設定。Privateでも構いません（Renderとの連携承認が必要）。
3. `Create repository` を押します。
4. 新しいリポジトリの `uploading an existing file`、または `Add file` → `Upload files` を開きます。
5. ZIPファイル自体はアップロードせず、ZIPを展開した**中身**をアップロードします。少なくとも以下がリポジトリのトップ階層に並ぶようにしてください。

```text
README.md
公開手順.md
server.py
render.yaml
requirements.txt
public/
  index.html
```

6. `Commit changes` を押します。GitHub上で `server.py` と `requirements.txt` がフォルダの中ではなくトップ階層に見えればOKです。

## 2. Renderで公開

1. https://dashboard.render.com/ を開いてログイン（または登録）。
2. `New` → `Web Service` を選択。
3. GitHubアカウントを連携し、先ほどの `kira-game-dx` リポジトリを選択します。
4. 次を指定します（自動入力されていればそのままで構いません）。

| 項目 | 値 |
| --- | --- |
| Name | `kira-game-dx`（既に使われていれば別名） |
| Language/Runtime | Python |
| Branch | main |
| Root Directory | 空欄 |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `python server.py` |
| Instance Type | Free |

5. `Deploy Web Service` をクリックします。デプロイログに `Live` / 起動成功が表示されたら公開完了です。
6. Renderに表示された `https://（サービス名）.onrender.com` を開きます。

**既存の「スーパーキラゲーム」のWeb Serviceを上書きせず、必ず新しいWeb Serviceを作ってください。**

## 3. 友達と遊ぶ

1. ホストが公開URLを開いて名前を入れ、部屋を作ります。
2. 人数、役職、議論・夜の時間を設定して、部屋コードまたは招待URLを共有します。
3. 参加者は同じURLを開いて各自の名前・部屋コードを入力。全員参加したらホストが開始します。

## 注意点

- Render無料Web Serviceは15分無通信だと停止し、次回アクセス時の復帰に時間がかかることがあります。
- 部屋・対戦データはサーバーメモリに保存されるので、Renderの再起動や再デプロイで消えます。
- 公開用のネット対戦・音声を複数実機で確認したわけではありません。友達を呼ぶ前に2端末で接続テストしてください。
- WebSocketを使用するため、このアプリを **Static Site** として作成しないでください。
- エラーが出たらRenderの `Logs` を確認してください。`requirements.txt` が見つからない場合はGitHubのフォルダ階層を見直してください。

## Discordでの遊び方

事前にDiscordで通話を開始してください。ゲーム中の議論フェーズで話し、指名・夜の時間は各自Discord側でミュートするなどして運用します。ゲーム内でマイク許可は不要です。
