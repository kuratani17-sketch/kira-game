# キラゲームDX Ver.0.3：既存のGitHub/Renderを更新する方法

## 既存の `kira-game` リポジトリを更新

今回のZIPには **`kira-game-dx-discord-render`** というフォルダが入っています。前回使ったリポジトリも同じフォルダ構成なら、**新しいRenderサービスやGitHubリポジトリは不要**です。

1. ZIPをPCで解凍します。
2. GitHubで今使っている `kira-game` リポジトリを開きます。
3. 青い `kira-game-dx-discord-render` フォルダがあるリポジトリの一番上で `Add file` → `Upload files` をクリックします。
4. 解凍した `kira-game-dx-discord-render` フォルダをアップロード画面にドラッグします。
5. `kira-game-dx-discord-render/server.py`、`kira-game-dx-discord-render/public/index.html`、`kira-game-dx-discord-render/public/roles/` 内の6画像がリポジトリに入ることを確認して、`Commit changes` をクリックします。
6. RenderのWeb Service画面で新しいデプロイが `Live` になったら更新完了。自動デプロイされない場合は `Manual Deploy` → `Deploy latest commit`。

注意：フォルダを二重にしないでください。誤：`kira-game-dx-discord-render/kira-game-dx-discord-render/server.py`。正：`kira-game-dx-discord-render/server.py`。

Renderの既存設定を確認する際は、`Settings` → `Build & Deploy`：

- Root Directory: `kira-game-dx-discord-render`
- Build Command: `pip install -r requirements.txt`
- Start Command: `python server.py`

## 別の構成の場合

解凍した**フォルダの中身だけ**をリポジトリ直下にアップロードするなら、RenderのRoot Directoryは空欄にしてください。上記のフォルダ構成を保つ方が、前回の設定を変更せずに済みます。

## 更新後の確認

1. ゲームのホーム画面に六役職のイラスト付き説明が表示される。
2. 待機部屋に「脱落時に役職を公開する」というチェックがある。
3. ゲーム開始時に各自の役職カードが中央に表示される。
4. 昼の指名画面に「本日の指名：±1」などの表記があり、2日目は±2になる。
5. 【公開情報】で非キラ確定した人は疑惑度0と表示され、指名候補から外れる。

Renderに更新をデプロイすると、進行中の対戦データは失われます。プレイしていない時間に更新してください。
